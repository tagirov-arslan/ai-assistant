# ИИ-ассистент с офлайн-распознаванием

Настольное приложение на `tkinter`, в котором ИИ-ассистент:

- принимает текстовые запросы пользователя;
- захватывает аудио с микрофона;
- преобразует человеческую речь в текст;
- отправляет запросы в LM Studio через встроенный программный модуль;
- получает ответ модели и отображает его в интерфейсе;
- преобразует текст ответа в речь.

## Возможности

- текстовый чат с историей сообщений;
- голосовой ввод через микрофон;
- распознавание речи через Vosk;
- озвучивание ответов ассистента;
- отдельный модуль `speech_module.py` для speech-to-text и text-to-speech;
- отдельный модуль `lm_studio_module.py` для подключения к LM Studio;
- статус текущего состояния приложения.

## Установка

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

1. Откройте LM Studio.
2. Загрузите модель и включите локальный API-сервер.
3. Запустите приложение:

```powershell
.venv\Scripts\python.exe app.py
```

## Использование

1. Укажите адрес LM Studio, обычно `http://127.0.0.1:1234`.
2. Нажмите `Проверить LM Studio` или `Обновить модели`.
3. Выберите модель.
4. Введите запрос вручную или нажмите `Голосовой ввод`.
5. Произнесите фразу в микрофон.
6. Ответ появится в ленте диалога и при включённой опции будет озвучен.

## Примечания

- `speech_module.py` работает в составе приложения и обслуживает захват микрофона, распознавание речи и озвучивание ответа;
- `text-to-speech` реализован локально через `pyttsx3`;
- `speech-to-text` реализован офлайн через `Vosk`;
- `lm_studio_module.py` подключает ассистента к локальному серверу LM Studio;
- по умолчанию используется модель `C:\Users\Macinery_knr\Desktop\jarvis-master\resources\vosk\vosk-model-small-ru-0.22`;
- LM Studio в проекте проверен по адресу `http://127.0.0.1:1234/v1/models`.
